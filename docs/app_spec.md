# iFont アプリ画面の仕様

生成機能に画面からさわれるようにするための仕様。中身は `ifont/encode.py` をそのまま呼ぶので、
生成のふるまいは今のコマンドラインと完全に同じになる。

## 形式

ローカルで動かすブラウザ画面。Python の標準ライブラリだけで作れる（`http.server`）。

```
python3 -m ifont.app        # → http://localhost:8765 を開く
```

外部ライブラリを足さないので、投稿までに環境の問題で動かなくなることがない。
ファイルは `ifont/app.py`（サーバ）と `ifont/app.html`（画面）の 2 つで足りる。

## 画面（1 画面で完結）

上から順に並べる。左に入力、右にプレビューでもよい。

### 1. 入力方法（ラジオボタン 2 つ）

- **(A) 文字列から作る**
- **(B) 音声と時間変化を読み込む**

選んだ方の項目だけを表示する。

### 2. (A) 文字列から作る

| 画面の項目 | 中身 | 対応するコマンドの指定 |
|---|---|---|
| 文字列 | 1 行のテキスト欄。例「まさかここであうとは」 | `text`（位置引数） |
| 表示方式 | フェード／部分表示／ぼかし解除／ワイプ の 4 択 | `--family fade\|reveal\|blur\|wipe` |
| 対象 | 全文字／先頭の 1 文字だけ の 2 択 | 後者のとき `--first-only` |
| 1 文字の長さ | 数値（ms）。初期値 350 | `--slot-ms 350` |

漢字とカタカナはひらがなに直してから渡す（今の encode がやる）。

### 3. (B) 音声と時間変化を読み込む

| 画面の項目 | 中身 | 対応するコマンドの指定 |
|---|---|---|
| 音声ファイル | wav を選ぶ | `--audio <path>` |
| 文字列 | 表示する文字列 | `text` |
| 各文字の開始時刻 | 「0,320,640,…」のようにカンマ区切り（ms） | `--onsets 0,320,640` |
| 時間変化のファイル | `time_ms,value` の 2 列 CSV | `--curve <path>` |
| 動かす文字 | その中でアニメーションさせる文字（決まり字） | `--kimariji ちは` |
| 表示方式 | (A) と同じ 4 択 | `--family` |

`--audio` と `--onsets` は必ず両方そろえる（片方だけならエラー）。

### 4. 生成

- ［生成］ボタン 1 つ。押している間は「生成中…」を出す。
- 終わったら、その場で `<video controls>` に流し込んで再生できるようにする。
- 「保存」リンクで mp4 を落とせるようにする。
- 画面の下に、実際に実行した内容を 1 行で出す（例
  `ifont "まさかここであうとは" --family blur --slot-ms 350`）。
  何をしたかが画面から分かるので、スクリーンショットが説明になる。

### 5. エラーの出し方

赤い 1 行で画面に出す。落とさない。

- 音声クリップが無い文字が入っている → その文字を挙げる
- `--audio` と `--onsets` の片方だけ指定された
- CSV の列が `time_ms,value` になっていない

## サーバ側（`ifont/app.py`）

| 経路 | すること |
|---|---|
| `GET /` | `app.html` を返す |
| `POST /generate` | 送られた項目を一時ディレクトリに保存し、`ifont.encode.main(argv)` を呼ぶ。出来た mp4 に id を振って返す |
| `GET /video/<id>` | その mp4 を返す（`Content-Type: video/mp4`） |

- 一時ディレクトリは `tempfile.mkdtemp()`。起動中だけ持つ。
- `encode.main()` は `SystemExit` を投げることがあるので受け止めて、その文言をそのままエラー表示に回す。
- 標準出力に出る「文字数／音声の長さ／方式／曲線の階層」も画面に出すと、
  どの文字がしっかり測った曲線でどの文字が暫定かが分かって親切。
