## 研究へのご協力のお願い

このたびは本研究へのご関心をありがとうございます。以下の説明をお読みいただき、内容にご同意いただける場合のみご参加ください。

### この研究の目的
本実験は、以下のいずれかを調べる研究です（参加する集団によって表示される文言が変わります。
実装: `startSession()` の `desc` オプション）。

- 聴覚の集団（acal）：**日本語のかな1文字が、どこまで聞こえれば分かるかを調べる研究です。**
- 視覚の集団（aprime・b）：**日本語のかな1文字が、どこまで表示されれば分かるかを調べる研究です。**
- 見え心地評価の集団（C）：**日本語のかな1文字が現れる様子について、続けて見ていられるかを調べる研究です。**

競技かるたなどで、音声を聞き取りにくい方にも公平に情報が届く「字幕」のデザインを考えるための基礎データを集めています。

### 何をしていただくか
- 聴覚の集団：かなの音声を、短く打ち切った状態で聞き、聞こえた文字を五十音表（かな表）から選びます。
- 視覚の集団：かなの文字が現れていく途中で打ち切られた画像を見て、見えた文字を五十音表から選びます。
  回答の選択肢は、ターゲットの字とまぎれ字を合わせて **68択** です（「4つの候補」ではありません）。
- 見え心地評価の集団（C）：文字が現れる4つの方式（フェード・部分表示・ぼかし解除・ワイプ）を見比べて、
  見ていて続けられるか等を7件法で評価します（**識別課題そのものは行いません**）。
- **回答時間の制限はありません。**（旧版の「1問あたり5秒以内」という記述は、この実験には当てはまりません。）
- 確信が持てなくても、感覚で答えていただいて構いません。成績で評価することはありません。

### 所要時間
較正フェーズ（聴覚acal・視覚aprime）はおよそ**10〜12分**、見え心地評価（C）はおよそ**7分**が目安です
（時間はブラウザ側の画面には現在表示されません。掲載時の募集文面に記載します）。
**【要確認】** 最終的な所要時間は掲載前の下見結果をもとに確定してください。

### 取得するデータ
この研究では、次のデータのみを記録します。
- 各設問でお選びになった文字と正誤、回答するまでの時間（ミリ秒）
- 表示・再生した刺激の設定情報（集団・条件・打ち切り時点など）
- 参加識別のための情報（クラウドソーシングの worker_id、参加者ごとにランダムに生成される**12桁の完了コード**）
- 端末の画面サイズなど、技術的な情報
- 中断して開き直した場合は、再開した回数と中断していた時間
- 聴覚の集団のみ：回答に使う機器（スピーカー／有線ヘッドホン／無線機器）の申告

### 個人情報について
- **お名前・ご住所・電話番号・メールアドレスなど、あなた個人を特定できる情報は一切収集しません。**
- 健康状態や障害の有無など、配慮を要する情報も収集しません。
- worker_id は、報酬をお支払いするための照合にのみ使用し、他の目的には使いません。

### 報酬と完了コードについて
- 実験を最後まで完了された方に、謝礼をお支払いします。目安は較正・検証フェーズ **200円程度**、
  見え心地評価（群C）**120円程度**です。**【要確認】** 金額は研究計画上「未確定」の扱いであり、
  掲載前に研究代表者が最終確定してください。支払い方式（PayPayポイント等）も
  **【要確認】** です（旧版の「PayPayポイント・360円程度」は別実験の値で、この実験には当てはまりません）。
- 実験の最後に画面に表示される**完了コード（12桁）**を、応募元（クラウドソーシング）の入力欄に貼り付けてください。
  これが報酬お支払いの対象となる確認になります（照合の詳細は [completion_code_flow.md](./completion_code_flow.md)）。
- 完了コードは控えておくことをおすすめします（後述の問い合わせの際に必要になる場合があります）。
- 見え心地評価（群C）では、完了コードが出るまでに評価データの送信を確認する処理が入っており、
  通信に失敗した場合は再送を試みる画面が出ることがあります。それでも送れない場合はコードを出したうえで
  「コードと時刻を控えて問い合わせてください」と案内します。

### 参加は任意です／いつでもやめられます
- 参加は**完全に任意**です。参加されなくても、あなたに不利益は一切ありません。
- 実験の途中でやめたくなった場合は、**いつでもブラウザを閉じて中断**できます。中断による不利益はありません
  （ただし、完了コードが出ないため、その回の報酬対象とならない場合があります）。
  - 【要確認：途中中断者への報酬の取り扱い方針があれば明記してください。】
- 同じブラウザで開き直せば、中断したところから再開できます（保存期限あり）。

### データの使われ方と保管
- 集めたデータは、Firestore（Google のデータベースサービス。プロジェクト ifont-transfer）に記録し、
  研究目的（解析・学会発表・論文・学位論文など）にのみ使用します。認証・ログインは求めません。
- 公表する際は、**統計的に集計した結果のみ**を用い、個人が特定される形で公表することはありません。
- データの保管：**収集したデータは本プロジェクトの運営中は保管し、研究終了時に完全に削除します。**
  データは Google Cloud Firestore（東京リージョン）に暗号化して保存し、研究責任者と共同研究者のみが
  アクセスします。（2026-08-24 確定。`experiment/transfer_config.js` の `contact.retention` と
  `docs/ethics_application_draft.md` 10.4 に同じ文言を入れてある。**3か所そろえること**）
  - 年数で期限を切らない書き方にしたのは、同じ研究室・同じ倫理審査委員会に出した姉妹研究
    Kikiwake が同じ形で審査を通しているためである。
  - ただし Kikiwake と違い、**この実験はメールアドレスなどの個人情報を一切集めない**
    （記録するのはクラウドソーシングの作業者IDだけ）。したがって「個人情報を削除する」ではなく
    **そもそも個人を特定できるデータが無い**と書くほうが正確である。
- 本研究は GitHub Pages（実験ページの配信）、Google Firebase（データ記録）、Yahoo!クラウドソーシング
  （募集・謝礼の支払い）といった外部サービスを利用します。これらのサービス上では各社の規約に基づいて
  情報が扱われますが、上記のとおり個人を特定する情報は収集しません。

## 補足：現行の同意画面の実装との対応

現行の同意画面（`prod_common.js:195-233` の `consentScreen` を土台に、
`transfer.js`/`transfer_comfort.js` の `tidyConsentScreen`・`consentExtraHTML` が調整を加えたもの）は、
以下の構成で表示されます。

1. 見出し「研究へのご協力のお願い」は転写検証実験では表示しません（`tidyConsentScreen` が除去。
   本文の説明文からそのまま始まります）。
2. 箇条書き：参加できる方（18歳以上）／記録するもの（回答・回答時間・識別子・技術情報。
   中断再開の回数と時間もここに統合）／記録しないもの（個人特定情報）／データの利用目的／中断・完了。
3. 聴覚の集団（acal）のみ：**再生機器の申告**（スピーカー／有線ヘッドホン／無線機器の3択）。
   この実験では**無線機器も選択可能**です（`allowWireless: true`。警告文は表示されますが、選ぶこと自体は禁止していません）。
   申告するまで「同意して始める」ボタンは押せません。
4. 転写検証実験で追加した3項目（`consentExtraHTML`）：**データの保管**・**同意の撤回**・**問い合わせ先**。
5. 環境についての案内文：聴覚・視覚の識別課題（acal/aprime/b）では、この案内文は同意画面には出ず、
   後続の「音量の確認」「見え方の確認」画面で出します（`noEnvNote: true`）。
   **見え心地評価（群C）では同意画面にそのまま表示されます**（「できればPC（パソコン）で、明るい静かな環境でお願いします。」）。
6. 末尾に「実施：津田塾大学 栗原研究室」の一文。

> 【要確認】本文書と実装は2026-08-22時点のソースコードに基づく。`transfer_config.js` の `contact`
> （研究責任者名・連絡先メール・保管期間）は掲載前に必ず埋めること。埋めた内容は自動的に
> 同意画面へ反映される（`consentExtraHTML` が `CFG.contact` を読むため、コード変更は不要）。
