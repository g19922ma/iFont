# 提案：68かな大実験の前に「転写が成立するか」を小さく確かめる

- 2026-08-19 丸山（AI議論をもとに起草）。栗原先生への提案。承認・修正をお願いします。
- 背景: 文献調査（project/文献調査_時間打ち切り知覚と清濁.md）で、時間打ち切りの測定自体は
  1961年からの系譜（竹内→桑原・境→片桐・東倉・古井）があると判明。新規性は「測ること」でなく
  「音声の“分かっていく時間構造”を、文字アニメーションとして作れるか」に置くのが強い。

## 提案の流れ

0. **研究の核**: 音声では文字情報が時間とともに徐々に識別可能になる。その「分かっていく過程」を
   文字アニメーションで再現できるか。（音声と視覚の情報量の等価・同期の価値は、まだ仮定しない）
1. **少数のかな（6〜10字）でターゲット曲線を作る**: 性質の違う字を選び、聴覚の識別曲線を
   **小規模実測**で取る（完成済みの統合セッションページの聴覚側を絞って使う。
   1人5分×20〜30人・数千円）。※文献の曲線は別話者・自然音声のため代用しない（曲線はプール固有）。
   先行研究は字の選定と予想形の指針に使う。
2. **小実験で「本当に作れたか」を確認**: 音声曲線をターゲットに時間変形したフェード表示を生成し、
   別の参加者で「50msで約20%・100msで約50%…」が視覚でも再現されるかを測る。
   比較対象は普通の線形フェード。ここで知りたいのは「良い感じか」ではなく「再現できたか」だけ。
3. **結果で分岐**:
   - A: 再現できる → 一般化へ（前半の字で調整し、残した字は追加測定なしで生成できるか）
   - B: 字ごとに違って移植できない → 「何が原因で転写できないか」（字ごとの較正が要るのか、
     子音・母音の特徴で予測できるのか）を次の問いにする。どちらでも研究になる。
4. **WISS**: 「音声で観測される文字識別の時間的進行を、動的文字表示として再現する手法」
   （問題→提案→プロトタイプ→小規模評価）。※WISSの締切を要確認。
5. **その後CHI方向**: 「分かるタイミングを揃えること」に人間的な意味がある場面
   （クイズ・競技・物語など“先に分かってしまう”が重要な場面）を別の問いとして調べる。

## 現行計画との差分

- **保留**: 全68かな×N=220人の本実験の発注（承認済みの実験計画書の実施を、小実験の結果まで延期）。
  刺激プール（配り方）の確定・音質診断（頭フェード・ぽ）は小実験でも必要なので**継続**。
- **維持・転用**: 統合セッションの実験ページ（そのまま小実験の測定装置）、
  フェード表示の実装（ステップ2の生成装置）、実験計画書（小実験版に縮約改訂）、
  Perceptual Score の概念整理（この提案の理論的骨格そのもの）。
- **新規性の主張の変更**: 「時間打ち切り知覚を測った」ではなく
  「既存の知覚知見と少数の実測から、別表現の“分かっていく時間構造”を生成できるか」。

## 決めていただきたいこと

1. この順序（小さく確かめてから広げる）で進めてよいか
2. 小実験の字の選定方針（性質の違う6〜10字。清濁ペアを入れるかは音質診断の結果待ち）
3. 投稿先の再設定（WISS締切の確認と、9/19目標だった論文計画との関係）
4. 68かな本実験の扱い（ステップ3-Aが通った後の較正実験として残すか）
