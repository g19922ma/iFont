# A1.5シミュレーション: 実験全体(群A測定→推定→生成→群B検証)を通した設計感度

- 2026-08-19 丸山。スクリプト: experiment/tools/sim_transfer_a15.py（乱数種20260820・300反復）
- A1への批判5点を反映: ①参加者の閾値差(SD10ms)・傾き差(±20%) ②文字ごとの転写誤差τを
  主ランダム効果に ③lapseは文字ごと1〜8%・推定でも自由パラメータ(Wichmann-Hill)
  ④群Aの推定誤差を生成に通す(視覚の真の曲線=群Aの推定値+ずれ。判定はμ̂B−μ̂A)
  ⑤時点配置ミスマッチ(急峻曲線×等間隔)も評価

## 要点

1. **N25/群×7時点×8文字は、現実的な条件でも成立**。
   現実的な成功(文字ごとの転写ムラτ=10ms)のもとで中点差の推定は +0.5±4.8ms。
   系統ずれ20msは +19.8±4.4ms(約4σ)で明確に区別でき、偏りもない。
2. **中点は頑健・不偏。傾きは二段階誤差が蓄積して偏る**(完全転写でも比0.95〜0.97、
   急峻曲線×配置ミスマッチでは0.85〜0.88まで低下)。
   → 設計含意: **主判定は中点の等価。傾きは幅広の副判定**とし、傾きの帯はA2で
   バイアス込みに較正する(そのまま±狭帯を使うと正しい方法を誤って落とす)。
3. 傾き0.6倍の劣化は 0.63±0.05 で検出可能(ただし上記バイアスと混ざるため副判定扱い)。
4. **文字ごとの転写ムラτ自体も推定できる**(τ=10ms→文字間差SDの推定10.5ms。
   ムラなし時の床は約5.7ms)。転写できない場合の「文字依存か」の分析(B分岐)も同じデータで可能。
5. 時点は7点維持を推奨(5点でも中点は成立するが傾きがさらに不安定)。
   時点配置は中点には鈍感だが傾きに効くため、A2で実曲線の形を見て決める。

## 残る簡易化(A2で解消)

- 生成の実現誤差を「推定ターゲット+正規ノイズ」で近似(実際の生成アルゴリズムの癖は未反映)
- 視覚の変換関数(不透明度→識別率)の較正誤差は未導入(生成方法が決まってから)
- 判定は点推定ベース(A2では等価検定の形式とCIを固定する)
