# 設計案：音声識別曲線 → 文字アニメーション生成（第2版・実装前・相談済み反映）

- 2026-08-19 丸山。第2版: V(o)の静止測定をやめ、**基準アニメーションの打ち切り測定 V_i(s) と
  time-warp 生成**に変更（丸山決定）。
- 研究の一言: **ある動的表現で測定された「分かっていく過程」を、別の動的表現の時間軸を
  変形することで再現できるかを検証する。**

## 1. 三段構成

1. **Audio identification trajectory**: 文字 i の音声識別曲線 A_i(t)（群Aで実測。t=音声の提示量）
2. **Inverse visual identification trajectory**: 基準アニメーション（線形フェード）を
   **進行度 s まで見せて打ち切ったときの識別率** V_i(s) を群A'で実測し、逆関数をとる
3. **Time-warped visual animation**: s_i(t) = V_i⁻¹( A_i(t) ) により、
   visual_i(t) = 基準アニメーション_i( s_i(t) )
   （「音声が50%識別された瞬間には、アニメを“50%識別される進行度”まで進める」）

- 音声（0→tを経験）と視覚（0→sを経験）が**対称な打ち切り課題**になり、
  静止提示とアニメ途中の等価という仮定が要らなくなる。
- **群A'の課題は、完成済みの統合セッションの視覚課題（線形フェードのfrac打ち切り）そのもの**。
  測定器は追加実装なしで流用できる。
- 残る仮定は「time-warp しても知覚が保たれるか」＝これがまさに群Bで検証する研究の問い。
  （Model 1: warp後も V_i(s) が保たれる／Model 2: 速度・履歴が効いて外れる。
  外れたらそれ自体が「単純な時間変形では移植できない」という結果）

## 2. V_i(s) の獲得戦略

- **戦略A（WISS最低ライン）**: 対象8文字それぞれの V_i(s) を群A'で実測
- **戦略B（stretch・成立条件にしない）**: leave-one-character-out——他7文字から作った共通 V(s) で
  残り1文字を生成できるかを、余力があれば試す（「未知文字への一般化」の初期結果）
- 戦略C（少量較正＋文字特徴で予測）はWISS後

## 3. 群Bの3条件（ベースライン設計）

| 条件 | 内容 | 何に答えるか |
|---|---|---|
| Baseline 1 | 線形フェード（等速） | 何もしない場合 |
| Baseline 2 | **50%識別時刻だけtargetに合わせた線形フェード** | 「提案法の良さは50%地点を合わせただけでは？」への直接の答え |
| Proposed | 曲線全体からの time-warp | 分かっていく形まで再現できるか |

## 4. 技術的詳細（フリーズ対象）

1. V_i(s) の当てはめ: s上のロジスティック（床 γ=1/72・lapse自由）をMLE。単調性はモデル形で保証
2. 逆関数は解析的に計算。天井・床の不整合はクリップ（A_i(t) が V_i の上限を超える時刻以降は
   s=100% に飽和、床未満は s=0%。発生範囲を記録・報告）
3. 出力: s_i(t) をフレーム時刻（60Hz）で評価した数値列
4. **フリーズ**: V_i の推定データ・当てはめ・逆変換・クリップ規則・全8字の s_i(t) 数値列を
   群B取得前にコミット固定。群Bを見てからの再調整は禁止

## 5. 刺激の設計哲学（8/19確定・音源見直し）

**オリジナルなのは cross-modal な転写だけ。刺激作成と測定はできる限り既存研究に寄せる。**

- 音声のゲーティング・同定・心理測定曲線・lapse込みfitting はすべて標準法（Grosjean/Furui/
  Sánchez-García/Wichmann-Hill）。視覚も打ち切り＋同定（Petersen & Andersen 的）で標準に乗せる
- 独自加工（200ms強制伸縮・F0平坦化・字ごとのVOT補正・文脈切り出し・字別フィルタ）は
  本実験刺激では**避ける方向**。「自然なかなの識別過程」を測るなら自然音声、
  合成を使うなら **raw TTS**（無加工で全長明瞭な声を選び、「このTTSについて成立」と限定）
- **音の長さは揃っていなくてよい**（絶対msで曲線を取る。time-warp生成は長さ不揃いでも成立）
- 音源決定の手順: 候補8字程度について A=自然録音／B=raw VOICEVOX／C=現行加工版 を
  全長で聴き比べ、無加工で明瞭なものを刺激候補にする（TTS選定は研究にしない。刺激QCとして行う）

### 刺激仕様（音源によらず固定）

1. **実験上の時間0 = acoustic onset**。WAV先頭に安全な無音paddingを持たせてよいが、
   打ち切り時間・frac計算は必ず acoustic onset 基準（ファイル先頭基準にしない）
2. 配信は **WAV**・再生の頭フェードなし（クリック対策はpadding側で行う）
3. 刺激QCは耳だけで完結させない: 全長で意図したかなに聞こえること＋
   acoustic onset・VOT・全長duration・peak/RMS・clipping無しの**機械的な一覧表**を必ず作る。
   可能なら本番前の少人数パイロットで全長識別率の高さを確認（同じ母集団での成立まで）
4. 旧刺激は上書きせず、バージョンを分けて保存する

## 旧5. （参考）現行加工版を使い続ける場合の修正方針（清濁診断の帰結）

- ぽ: 文脈切り出しをやめ**単独合成＋VOT自動修正**へ
- ぱ: 手動処方（子音倍率固定・強い高域減衰）を外して再生成／修正
- onset-F0温存: 当面保留（比較材料として保存。ぴ・かは平坦化でも清に聞こえている）
- 修正版は全長提示の小さな識別確認を通す
- **最終刺激は WAV 配信・再生の頭フェードなし**（今回の診断では主要因ではなかったが、
  数十msの初期情報を測る実験で不要な信号加工を残す理由がないため）
- 清濁境界の数値は固定的に扱わない（知覚境界は音素・話者・文脈で変わる。
  診断は「濁って聞こえる2字が極端に短いVOTを持ち、単独生成で伸びた」という刺激QCの証拠として使う）

## 6. 主張の限定（執筆時の規律・8/19確定）

**WISSの主張文（この範囲を超えない）**:
> 音声と文字アニメーションのそれぞれについて測定した識別軌跡を用い、音声の識別過程を
> 文字アニメーションの time-warp として再構成する手法を提案する。独立参加者によって、
> その再構成精度を検証する。

- 新規性の置き場所: 「逆関数の新アルゴリズム」ではなく、
  **「ある表現で観測された時間的な識別過程を、別の動的表現として実際に再構成できるのかを
  初めて実証的に問う」**こと。強さは Baseline 2（中点だけ合わせ）と Proposed の差で決まる。
- A'の打ち切り測定にも仮定は残る（time-warp後は同じ進行度でも速度履歴が違う）。
  これは欠陥ではなく、**本検証が「基準アニメで測った知覚曲線は time-warp後にも利用可能か」の
  テストを兼ねる**と明記する。Model 1/2 を事前に解決する必要はない。

**言ってはいけないこと（執筆時の禁止リスト）**:
- 「異なるモダリティ間の知覚を一般的に変換できる」
- 「同じ正答率＝同じ情報量／同じ理解度」
- 8文字を全較正しているのに「未知の文字にも生成できる」と読ませる書き方
- inverse mapping 自体をアルゴリズム上の大発明として売る

**言ってよいこと**:
- 「十分な心理物理的較正があれば、ある動的表現の識別軌跡を別の動的表現で再構成できる（かを検証した）」
- （Baseline 2 との差が出た場合）「表示の速さを合わせるだけでは足りず、識別曲線全体を使う意味がある」

## 7. 群構成

群A（音声・8字×7時点） → 群A'（基準アニメ打ち切り・8字×7進行度） → 生成・フリーズ →
群B（3条件×8字×7時点）。3群とも独立参加者。人数・水準はA2シミュレーションで確定
（A1.5の暫定: 各群25人）。
