# 設計案：音声識別曲線 → 文字アニメーション生成（第2版・実装前・相談済み反映）

- 2026-08-19 丸山。第2版: V(o)の静止測定をやめ、**基準アニメーションの打ち切り測定 V_i(s) と
  time-warp 生成**に変更（丸山決定）。
- 研究の一言: **ある動的表現で測定された「分かっていく過程」を、別の動的表現の時間軸を
  変形することで再現できるかを検証する。**

## 1. 三段構成

1. **Audio identification trajectory**: 文字 i の音声識別曲線 A_i(t)（群Aで実測。t=音声の提示量）
2. **Inverse visual identification trajectory**: 基準アニメーション（線形フェード）を
   **進行度 s まで見せて打ち切ったときの識別率** V_i(s) を群A'で実測し、逆関数をとる
3. **Time-warped visual animation**: s_i(t) = V_i⁻¹( A_i(t) ) により、
   visual_i(t) = 基準アニメーション_i( s_i(t) )
   （「音声が50%識別された瞬間には、アニメを“50%識別される進行度”まで進める」）

- 音声（0→tを経験）と視覚（0→sを経験）が**対称な打ち切り課題**になり、
  静止提示とアニメ途中の等価という仮定が要らなくなる。
- **群A'の課題は、完成済みの統合セッションの視覚課題（線形フェードのfrac打ち切り）そのもの**。
  測定器は追加実装なしで流用できる。
- 残る仮定は「time-warp しても知覚が保たれるか」＝これがまさに群Bで検証する研究の問い。
  （Model 1: warp後も V_i(s) が保たれる／Model 2: 速度・履歴が効いて外れる。
  外れたらそれ自体が「単純な時間変形では移植できない」という結果）

## 2. V_i(s) の獲得戦略

- **戦略A（WISS最低ライン）**: 対象8文字それぞれの V_i(s) を群A'で実測
- **戦略B（stretch・成立条件にしない）**: leave-one-character-out——他7文字から作った共通 V(s) で
  残り1文字を生成できるかを、余力があれば試す（「未知文字への一般化」の初期結果）
- 戦略C（少量較正＋文字特徴で予測）はWISS後

## 3. 群Bの3条件（ベースライン設計）

| 条件 | 内容 | 何に答えるか |
|---|---|---|
| Baseline 1 | 線形フェード（等速） | 何もしない場合 |
| Baseline 2 | **50%識別時刻だけtargetに合わせた線形フェード** | 「提案法の良さは50%地点を合わせただけでは？」への直接の答え |
| Proposed | 曲線全体からの time-warp | 分かっていく形まで再現できるか |

## 4. 技術的詳細（フリーズ対象）

1. V_i(s) の当てはめ: s上のロジスティック（床 γ=1/72・lapse自由）をMLE。単調性はモデル形で保証
2. 逆関数は解析的に計算。天井・床の不整合はクリップ（A_i(t) が V_i の上限を超える時刻以降は
   s=100% に飽和、床未満は s=0%。発生範囲を記録・報告）
3. 出力: s_i(t) をフレーム時刻（60Hz）で評価した数値列
4. **フリーズ**: V_i の推定データ・当てはめ・逆変換・クリップ規則・全8字の s_i(t) 数値列を
   群B取得前にコミット固定。群Bを見てからの再調整は禁止

## 5. 刺激の最終方針（清濁診断の帰結・丸山決定 8/19）

- ぽ: 文脈切り出しをやめ**単独合成＋VOT自動修正**へ
- ぱ: 手動処方（子音倍率固定・強い高域減衰）を外して再生成／修正
- onset-F0温存: 当面保留（比較材料として保存。ぴ・かは平坦化でも清に聞こえている）
- 修正版は全長提示の小さな識別確認を通す
- **最終刺激は WAV 配信・再生の頭フェードなし**（今回の診断では主要因ではなかったが、
  数十msの初期情報を測る実験で不要な信号加工を残す理由がないため）
- 清濁境界の数値は固定的に扱わない（知覚境界は音素・話者・文脈で変わる。
  診断は「濁って聞こえる2字が極端に短いVOTを持ち、単独生成で伸びた」という刺激QCの証拠として使う）

## 6. 群構成

群A（音声・8字×7時点） → 群A'（基準アニメ打ち切り・8字×7進行度） → 生成・フリーズ →
群B（3条件×8字×7時点）。3群とも独立参加者。人数・水準はA2シミュレーションで確定
（A1.5の暫定: 各群25人）。
