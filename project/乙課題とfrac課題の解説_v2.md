## 0. 全体の見取り図

### 0.1 iFontが作りたいもの

競技かるたや早押しクイズは、言葉が音声で少しずつ届くからこそ「どこで分かるか」を競える遊びである。文字で全部見せてしまえば勝負にならない。だから聴覚に頼れない人は、この遊びのおもしろさごと閉ざされている。普通の字幕は一度に全部見えてしまうので、代わりにならない。

iFontは、**文字を「少しずつ分かるように」時間をかけて見せることで、目でも同じ勝負を成立させる**。設計目標は一文で書ける。

> 音声を聞いている人と、字幕を見ている人が、**同じ時点に同じだけ分かる**こと。

これを実現するには、感覚に頼らず数値が要る。かな1文字について「音をどこまで聞かせたら何％の人が分かるか」と「字をどれだけ見せたら何％の人が分かるか」を測り、**同じ認識率になる点どうしを対応づける**。この対応づけを**変換 g** と呼ぶ。gが決まれば、音声の進み方に合わせて各字の見せ方を機械的に設計できる。

### 0.2 提示速度という軸

ここで、はじめに押さえておくべき軸がある。**提示速度**である。

運用では、かなが一定の速さで次々に届く。1モーラあたり何ミリ秒か、というこの速さを**提示速度**と呼ぶ。iFontの基準は **1モーラ 200ミリ秒（毎秒5.0モーラ）** である。競技かるたの読み上げ規則がこの速さで、日本語能力試験のもっとも易しい級の聴解音声（毎秒5.05モーラ）ともほぼ一致する。**聴覚の刺激もこの速さで合成してある。**

そして、ある提示速度でiFontを成立させるには、**2つのものが必要になる**。

1. **その速度で続けて出しても、認識が落ちないという保証。** 文字が次々に来ることで手前の文字の認識が妨げられるなら、孤立して測った曲線は運用の場面を予測しない。
2. **その速度での認識率曲線。** かな1文字ごとに、どこまで提示すれば何％の人が分かるかの曲線。

**乙課題が1を、frac課題が2を引き受ける。**

### 0.3 2つの課題の役割

本実験は2段階で行う。

**第1段階の乙課題では、どの提示速度まで使えるかを決める。** かなを3つ続けて提示し、間隔を7水準に振って、後ろから次の文字が来ることで手前の文字の認識が落ちないかを判定する。確認的な主判定は基準速度の200ミリ秒で行い、他の水準は副次的な判定として扱う。

**第2段階のfrac課題では、その速度での曲線を測る。** かな1文字（1音）をどこまで提示すれば分かるかを0％から100％まで21段階で掃引し、字ごとの認識率曲線を推定する。

```
  第1段階  乙課題 ──→ 「この提示速度で続けても認識は落ちない」という保証
                              │
                              ↓ この保証があってはじめて使える
  第2段階  frac課題 ──→ その速度での字ごとの認識率曲線 ──→ 変換 g ──→ 字幕の設計
```

どちらが欠けても、gという数値は意味を持たない。乙課題は主結果ではなく、主結果を成立させる条件を確かめる課題である。予算の配分もそうしてある（乙課題2本で約2.7万円、frac課題4本で約8万円）。

なお「乙課題」は内容を表す名前ではない。この文書では**較正の課題**という言い方も併用する。frac課題の frac は fraction（割合）で、刺激をどこまで提示したかの割合を指す。

## 1. 乙課題でやること — どの提示速度まで使えるかを決める

### 1.1 課題の形

**かな（音）を3つ続けて提示し、間隔Sを変えながら、1番目と2番目が何だったかを答えてもらう。**

```
   ＋       1文字目      2文字目      3文字目      白紙        → 1番目 → 2番目 の順に回答
  注視点   ├── S ──┤ ├── S ──┤ ├── S ──┤
```

間隔Sが提示速度そのものである。**50・83・133・200・300・450・700ミリ秒**の7水準を振る。毎秒のモーラ数に直すと20・12・7.5・5.0・3.3・2.2・1.4になる。

- 1人あたり練習2問と本番42問（各水準6問）、所要は10分前後
- 聴覚版（68音）と視覚版（72字）を、同じ設計で別々に実施する
- 3つの刺激はすべて別の字（音）にする。同じ字が再登場すると「最初の字は何だったか」の判断が壊れるため
- 字の割り当ては混ぜた一覧から順に配る。同じ字が偶然何度も出て、特定の水準の成績を歪めることを防ぐ
- 各試行は参加者がボタンを押してから始まる。押すまで回答は選べない
- 画面に実際に表示された時刻と、端末の画面書き換え頻度を毎回記録する

### 1.2 判定に使うのは1番目

**主判定に使うのは1番目の正答率だけ**である。1番目は、後ろから2番目・3番目が来る状況で提示される。だから「後続の文字によって、手前の文字の認識が妨げられるか」をそのまま測っている。

2番目も答えてもらうが、その正答率は副次的な指標として扱う。理由は1.6節で述べる。

3番目は答えない。それでも3番目を出すのは、**2番目の見え終わり・聞こえ終わりを、実際の運用と同じ形（次の文字が来る）にそろえるため**である。運用では文字が延々と続くので、どの文字にも必ず次の文字が来る。3番目を出さないと2番目だけが「後ろに何も来ない特別扱い」になり、1番目と条件が揃わない。

### 1.3 頭打ちと比べる

判定は、**間隔を十分長くとったときの成績**を基準に行う。

参加者ごとに耳や目の良さは違うし、その日の集中も違う。だから「0.2秒間隔での正答率が70％」という数字だけでは、良いのか悪いのか判断できない。そこで450ミリ秒と700ミリ秒の水準を同じ人に同じセッションで行ってもらう。ここでの成績がその人の「急かされていないときの実力」であり、これを**頭打ち**と呼ぶ。

判定するのは次の量である。

> **Δ ＝（頭打ちの正答率）−（判定する速度での正答率）**

同じ人の中の引き算なので、個人差も日による調子も消える。

### 1.4 判定の手続き

「差が有意でなかった」は「差がない証拠」にならない。雑な実験ほど有意差は出にくいので、手を抜くほど「干渉なし」に見えるという倒錯が起きる。そこで**非劣性検定**を使う。「差はゼロか」ではなく「**差は、実務上どうでもいいと言えるくらい小さいか**」を問い、その境界を**マージン δ** として、データを見る前に決めておく。

判定は差Δの信頼区間の位置で3つに分かれる。

| 信頼区間の位置 | 結論 | 意味 |
|---|---|---|
| 上限がδより小さい | **干渉なし** | 劣化はδ未満だと自信を持って言える |
| 下限も0より大きい | **干渉あり** | 本当に劣化している |
| δをまたぐ | **保留** | データが足りず、まだ言えない |

予算を段階的に使う二段階の手続きをとる。

- **第一段**: 聴覚60名・視覚40名、δ＝8ポイントで判定する
- **第二段**: 保留になったときだけ、聴覚130名・視覚80名まで増員し、δ＝5ポイントで判定し直す
- 検定は各段とも片側2.5％とし、二段階を通じた誤りの確率を5％以内に保つ

1万回のシミュレーションによる判定確率は次のとおりである。

| | 第一段で「干渉なし」 | 最終的に「干渉なし」 | 最終的に「保留」 |
|---|---|---|---|
| 聴覚 | 77.6％ | **84.5％** | 11.7％ |
| 視覚 | 89.3％ | **92.7％** | 4.5％ |

本当に8ポイントの劣化があるときに「干渉あり」と検出できる確率は、両モダリティとも96％である。

### 1.5 δ＝8ポイントの根拠

δは分野横断の既定値が存在しない値で、「研究の中身から正当化して事前に決めよ」というのが規範である。参考までに、割合を評価する医学の試験では10ポイントを置くことが最も多い。

iFontの根拠は**測定の精度**である。frac課題は字ごとに約88観測を集める設計で、このとき字ごとの推定の標準誤差は約5.4ポイントになる。**推定の誤差より小さい一様な劣化は、字ごとの曲線の順位を変えないので、gの設計を変えない。** この論法から、第一段の8ポイントと増員後の5ポイントが出ている。医学の相場の10ポイントより厳しい側である。

### 1.6 2番目も答えてもらう理由

2番目の正答率は、3番目による後ろからの妨害と、2つ覚えておくという記憶の負荷とが混ざった量になる。単一の原因に帰せないので、副次的な指標として扱う。それでも回答してもらうのは、**データのためではなく、課題の要求を運用の場面と同じにするため**である。

実際の運用では、読み手はどの文字も読み取ろうとしている。「1番目だけ答えればよい」と教示すると、課題は「最初の1文字を取ったら、あとの2つは無視してよい」に変わる。すると、測ろうとしている干渉のうち**後続の文字を処理するために資源が取られるぶん**が落ちる。これは干渉を小さく見積もる方向、すなわち「干渉なし」という結論に有利な方向のバイアスである。非劣性を主張する実験で、自分の結論に有利なバイアスは避けなければならない。

負担の配分にも配慮してある。**1番目を先に答えてもらう**ので、判定に使う項目は保持時間が最短で、五十音表を探すことによる干渉も受けない。長い保持と探索の負担は、副次的な2番目のほうに寄せてある。

なお、2つ覚えることによる負荷は頭打ちの水準を下げうる。この影響は数値で押さえてあり、頭打ちが70％から60％に下がっても「干渉なし」の判定力は85.4％から81.9％にとどまり、誤判定率は名目どおりに制御される。また判定は同じ人の中の引き算なので、一様にかかる負荷は打ち消される。

### 1.7 主判定は200ミリ秒、他の水準は副次判定

7水準すべてを測るが、**確認的な主判定は基準速度の200ミリ秒で行う**。二段階の設計も必要人数の計算も、この1点を前提に組んである。

残りの水準は、あらかじめ定めた**副次的な判定**として扱う。ここから2つのものが得られる。

1. **非劣性を保てる最速の提示速度。** 提示速度を「かるたの読み上げ規則だから0.2秒」と借りてくるのではなく、**成績が落ちない最速の速度を実測して選んだ**と言えるようになる。
2. **133ミリ秒での保証。** これが、frac課題の視覚1文字課題で133ミリ秒の条件を置く根拠になる（2.7節と3.1節）。

追加の参加者も費用もかからない。7水準はもともと測るからである。

### 1.8 乙課題で分かること・分からないこと

| | 内容 |
|---|---|
| 分かる | 各提示速度で、手前の文字の認識が単独提示より落ちるかどうか／落ちない最速の速度はどこか／聴覚と視覚で干渉の様子がどう違うか |
| 分からない | **字ごとの曲線**。乙課題は間隔だけを変えて全体の正答率を見る課題で、字ごとの推定に必要な観測数はない。曲線はfrac課題の担当である |

## 2. frac課題でやること — その速度での曲線を測る

### 2.1 課題の形

かな1文字（1音）を**途中まで**提示して、それが何だったかを答えてもらう。「途中まで」の度合いを0％から100％まで **21段階**（0・5・10・…・95・100）で変えながらくり返すと、提示の度合いに対する正答率の曲線が引ける。これがそのまま認識率曲線である。

| | 「途中まで」の意味 | 0％のとき | 100％のとき |
|---|---|---|---|
| 聴覚 | 音声の先頭から一部だけ再生して打ち切る | 何も聞こえない | 音が最後まで鳴る |
| 視覚 | 字がだんだん鮮明になる途中で消す | 何も見えない | 字が完全に現れる |

fracは「どこまで進んだか」を表す無次元の量なので、**実際の露光時間は frac × 提示速度**になる。提示速度200ミリ秒でfrac＝50％なら、露光は100ミリ秒である。

**聴覚の打ち切りは、音響的な立ち上がりの位置を起点にする。** 合成した音声ファイルの先頭には40〜90ミリ秒の無音があるので、ファイルの先頭を起点にすると、低い割合の条件が全部「ただの無音」になってしまうためである。

**視覚の鮮明化は1種類の見せ方に固定する**（透明度がだんだん上がる fade を想定）。見せ方を複数用意すると、字ごとの観測がその数だけ分割され、必要な人数がそのぶん増えるからである。

回答は、**50音表の形に並んだ固定のグリッドから1つを選んでもらう**。表は毎回同じ並びなので、探す手間が試行ごとに変わらない。強制選択なので「分からない」と書かれて解析できなくなることもない。分からなくても勘で答えてもらう。選択肢が多いので当てずっぽうで当たる確率は1〜2％しかなく、曲線の下限がほぼ0から始まる。

### 2.2 4つの課題

| 課題 | 提示するもの | 答えるもの | 提示速度 | 何を測るか |
|---|---|---|---|---|
| **聴覚1文字** | 1音をfrac％で打ち切る | その音（68音から） | 200ms | 音ごとの認識率曲線 |
| **聴覚2文字** | 前の音を全部、続く音をfrac％で打ち切る | 後ろの音（68音から） | 200ms | 前の音とのつながりが認識をどれだけ助けるか |
| **視覚1文字** | 1字をfrac％まで鮮明にして消す | その字（78字から） | **200msと133ms** | 字ごとの認識率曲線と、その速度依存性 |
| **視覚2文字** | 前の字を全部、続く字をfrac％で打ち切る | 後ろの字（78字から） | 200ms | 前の字が残る提示の効果 |

**聴覚は200ミリ秒の1点だけである。** モーラの長さを変えることは別の合成をすることであり、母音の崩れや子音の相対的な位置が変わって、速度と音の中身が混ざるためである。視覚の字は何ミリ秒で出しても同じ画像なので、速度だけを独立に操作できる。この非対称は、**文字が持続する物体であり、音声が時間上の出来事である**というモダリティの本質的な違いの現れでもある。

### 2.3 聴覚が68で視覚が78である理由

音と字は1対1に対応していない。

**音が68種類**なのは、日本語で互いに聞き分けられる音だけを数えたからである。「を」は「お」と、「ぢ」は「じ」と、「づ」は「ず」と、現代の標準的な発音では同じ音になる（合成音声でも実際に同一の音声データになる）。「ゔ」も多くの人が「ぶ」と区別して聞かない。これらは出題からも回答からも外す。「っ・ゃ・ゅ・ょ」はそれ単独では音にならないので、もともと音の側に存在しない。

**字が78種類**なのは、画面に実際に出る字形を全部数えたからである。iFontは表記どおりに字を出すので、「を」「ゐ」「ゑ」も小書きの字もそのまま画面に現れる。とくに百人一首では、札が取れるかどうかを決める先頭2文字の領域に「を」が21組も現れる。

このずれは**読みでつなぐ**。同じ音を持つ字はその音の曲線と同期させる（を↔オ、ゑ↔エ、ゐ↔イ、ゔ↔ブ）。音を持たない小書きの字は、隣の字と組にする描画の規則で同期させる。

### 2.4 字ごとに1本ずつ推定する

かな全体で1本の曲線を引けば話は簡単だが、それでは足りない。**字によって難しさがまるで違う**からである。ごく短い提示で最後まで取れないのは、たいてい濁点・半濁点の有無である（「ぎ」を「き」と、「ぷ」を「ぶ」と取り違える）。字形が似ている組や、母音だけが違う組も混同されやすい。全体の平均で1本の曲線を引くと、こうした構造が全部ならされて消えてしまう。

実際の字幕を設計するときに必要なのは平均ではなく、**濁点のある字はどれだけ長めに・鮮明に出せばよいか**という字ごとの答えである。

観測が少ない字も安定して推定できるように、解析では**字を変量効果に置いた階層モデル**を使う。全体の傾向を借りながら各字の個性を推定する方法で、字ごとに独立に推定するよりずっと少ない観測で曲線が引ける。

**目標は字（音）ごとに約88観測を21段階に散らすこと**である。1つの段階あたり平均4観測ほどにしかならないが、推定するのが段階ごとの独立な値ではなく**なめらかな1本の曲線**なので、これで足りる。この88観測が字ごとの標準誤差 約5.4ポイントを与え、それが1.5節のδ＝8ポイントの根拠になっている。**速度や条件の水準を持つ課題では、水準ごとにこの88観測を確保する。**

### 2.5 副産物 — 混同の構造

frac課題は「当たったか外れたか」だけでなく、**外れたときに何と間違えたか**を全部記録する。ここから**混同行列**——どの字がどの字と取り違えられるかの表——が作れる。

これは聴覚の音声研究で古くから使われてきた記述の形式である。iFontの視覚側の測定を、聴覚研究と同じ通貨で語れるようになる。「視覚の理解度が何％」ではなく「どの字とどの字が、どの提示量で分離するか」という水準で、聴覚と視覚を突き合わせられる。

### 2.6 聴覚2文字課題 — 共調音の寄与

前の音（C1）を最後まで提示してから、目標の音（C2）を途中で打ち切り、**C2が何だったか**を答えてもらう。

日本語の流暢な発話では、前の音の終わりに次の音の準備がすでに現れている（共調音）。だから「か」の後の「き」と、単独の「き」とでは、物理的な音が違う。実測でも、同じかなでも単独の発音と語中の発音の違いは、別のかなどうしの違いの**約2倍**あった。

したがって「単音の曲線を合成すれば連続音声を予測できるか」は、それ自体が検証すべき問いになる。1文字課題が**測定の原子**、2文字課題が**結合を含む分子**、製品の流暢な音声が**その先**という3層の構造である。

### 2.7 視覚1文字課題 — 200ミリ秒と133ミリ秒

字が0％から100％まで鮮明になるのにかける時間を、**200ミリ秒**と**133ミリ秒**の2水準にする。同じ参加者が両方を行う。

| 速度 | 毎秒のモーラ数 | 位置づけ |
|---|---|---|
| **200ミリ秒** | 5.0 | **基準速度**。聴覚の刺激もこの速さで作ってあるので、聴覚と視覚を対応づけられるのはこの点である |
| **133ミリ秒** | 7.5 | アナウンサーの標準的な読み上げに相当。日本語能力試験の最上級（毎秒7.07モーラ）をわずかに上回る。乙課題の間隔の水準にも133ミリ秒がある |

**この2水準は、対等な2つの運用点ではない。** 役割が違う。

**200ミリ秒は変換gを作るための点である。** 聴覚の曲線がこの速度でしか存在しないので、聴覚と視覚を認識率で結べるのはここだけである。

**133ミリ秒は、視覚の曲線が提示速度にどう依存するかを測るための点である。** これ単独ではgを与えない（聴覚側の相手がいないため）。測る意味は次の問いに答えることにある。

> **認識率は「どれだけの時間見えていたか」だけで決まるのか、それとも「どれだけ速く現れたか」にも依存するのか。**

2つの速度では露光時間の範囲が重なる（0〜133ミリ秒の部分）ので、この重なりを使って両者を分離できる。露光時間だけで決まるなら、視覚の曲線は速度をまたいで移せる。依存するなら、速度ごとに測り直さなければならないことが分かる。**どちらであるかは、この測定なしには言えない。**

なお、133ミリ秒の**測定そのもの**には乙課題の保証は要らない。孤立した1文字を測るだけだからである。保証が要るのは、その曲線を133ミリ秒で動く製品に**持ち込むとき**であり、それは乙課題の133ミリ秒水準の副次判定が担う（1.7節、3.1節）。

### 2.8 視覚2文字課題 — 先行文字の残存を2条件

提示速度は基準の200ミリ秒に固定し、2文字目が出ているあいだの1文字目の扱いを2水準にする。同じ参加者が両方を行う。

- **統制の条件**: 1文字目が消えてから2文字目が出る
- **残存の条件**: 2文字目が出ているあいだも、1文字目が薄くなりながら同じ枠に重なって残る。薄れ方は指数減衰で、時定数は聴覚で前の音が後の音に影響する時間の長さから決める

これを測るのは、**流暢な音声には時間の文脈がもともと入っている**からである。前の音の響きが残り、次の音の準備が先に聞こえる。素の字幕にはそれがない。つまり1文字ずつ順に出すだけの提示は、流暢な音声の視覚的な等価物ではなく、**音を単純につなげただけの音声の等価物**にとどまる。残存の条件は、聴覚が無償で持っている時間の文脈を、視覚に同じ量だけ移植する試みである。

**測定が壊れない理由。** 答えるのは2文字目である。この条件で増えるのは**1文字目の見える時間だけ**で、2文字目の見える時間は一切変わらない。したがって「長く見せただけではないか」という反論が当たらず、露光量をそろえるための追加の条件を立てずに済む。実装でも、両条件で2文字目の実測提示時間が完全に一致することを1512通りの組み合わせで確認してある。

**成績が下がる可能性も予測として書いておく。** 消えた刺激が後から現れた刺激の知覚を妨げるという現象が知られており、その効果は0.2秒前後の帯域で最大になる。どちらに転んでも、時間の文脈が視覚でどう働くかについての知見になる。

### 2.9 出題の配り方と品質管理

- 毎回独立にくじを引くのではなく、**水準ごとに均等な試行数を割り当ててから順序を混ぜる**。独立なくじ引きだと段階ごとの試行数がばらつき、観測が1つも入らない組み合わせが出るためである。字の出現も同様に均等化する。
- **水準を持つ課題では、水準ごとに88観測を確保する。** 視覚1文字が本番320試行（速度ごとに160）、視覚2文字が本番400試行（条件ごとに200）なのはこのためである。水準を2つに割ったまま試行数を据え置くと、標準誤差が約7.6ポイントに悪化してδの正当化が崩れる。
- 全体の5％を、**最後まで提示する統制の問題**として混ぜる。まじめに取り組んでいれば高い確率で正解する問題である。
- この統制問題の正答率が半分に満たない回答者は解析から除く。まじめな参加者が誤って除かれる確率は1.2％と見積もられる。
- 各問は参加者がボタンを押してから始まる自己ペース方式で、押すまで回答は選べない。
- 画面に実際に表示された時刻と、端末の画面書き換え頻度を毎回記録し、名目の値ではなく実測値で解析する。

### 2.10 frac課題で分かること・分からないこと

| | 内容 |
|---|---|
| 分かる | かな1文字ごとの認識率曲線（聴覚68音・視覚78字）／どの字がどの字と混同されるかの構造／基準速度での変換 g／**前から後ろへの影響**——先行する文字（音）が、あとに来る文字の認識をどれだけ助けるか、あるいは妨げるか／視覚の認識率が提示速度にどう依存するか／視覚に時間の文脈を足すと認識がどう変わるか |
| 分からない | **後ろから前への影響**——その文字の後ろに次の文字が来ることによって、その文字自身の認識が妨げられるかどうか。frac課題は答えてもらう文字を系列の**最後**に置くので、この向きは構造的に測れない。これは乙課題の担当である |

## 3. 2つの課題の関係

### 3.1 提示速度ごとに、保証と曲線が対になる

乙課題の保証も、frac課題の曲線も、**提示速度ごとに存在する**。iFontを成立させるには、その速度で両方がそろわなければならない。実際にそろうのは次のとおりである。

| 提示速度 | 毎秒モーラ | 乙課題 | 聴覚の曲線 | 視覚の曲線 | 変換 g |
|---|---|---|---|---|---|
| 700・450ms | 1.4・2.2 | 基準（頭打ち） | — | — | — |
| 300ms | 3.3 | 副次判定 | — | — | — |
| **200ms** | **5.0** | **主判定** | **○** | **○** | **○** |
| **133ms** | **7.5** | **副次判定** | — | **○** | — |
| 83・50ms | 12・20 | 副次判定 | — | — | — |

読み方は3つある。

**変換gが定義できるのは200ミリ秒だけである。** gは聴覚の曲線と視覚の曲線を認識率で結ぶものなので、両方がそろう速度でしか作れない。聴覚の曲線は200ミリ秒の1点しかないので、gも1点である。これは制約であり、限界として正直に書く。

**133ミリ秒は、視覚の曲線の速度依存性を測る点である。** gを2つ作るためではない。ここで得られるのは「視覚の認識率が露光時間だけで決まるのか、現れる速さにも依存するのか」という答えで、これは視覚の性質そのものなので、聴覚側の相手がいなくても意味を持つ。将来この速度で聴覚の曲線を測れば、そのときgが作れる。

**133ミリ秒を運用に使えるかどうかは、乙課題の133ミリ秒水準が決める。** 副次判定で「干渉なし」なら、その速度での連続提示は安全である。「干渉あり」なら、133ミリ秒は運用点として使えない。ただしその場合でも視覚の速度依存性という知見は残り、加えて**使ってよい速度の上限が200ミリ秒と133ミリ秒のあいだにある**ことが分かる。どちらに転んでも無駄にならない。

### 3.2 影響の向きで分担している

frac課題には2文字版があるので、「文字が続く場面」はもう測れているように見える。しかし**2つの課題は、測っている影響の向きが違う**。

| | 答える文字 | その前 | その後ろ | 測れる影響の向き |
|---|---|---|---|---|
| frac課題（2文字版） | 2文字目 | 1文字目（最後まで提示） | **何も来ない** | 前 → 後ろ |
| 乙課題 | 1文字目 | 何も来ない | 2文字目・3文字目 | **後ろ → 前** |

frac課題は文字数の問題で不足しているのではない。**答える文字を系列の最後に置く設計なので、後続による妨害が入り込む余地が構造的にない**のである。

### 3.3 向きの重要度は、聞くことと見ることで逆になる

ある刺激が別の刺激の知覚を妨げるマスキングには2つの向きがあり、**どちらが強いかが聴覚と視覚で逆**である。

- **聴覚では、前から後ろへの妨害が強い。** 前の音の響きが次の音にかぶり、その影響は数百ミリ秒におよぶ。逆向きは20ミリ秒に満たない。
- **視覚では、後ろから前への妨害が強い。** あとから同じ場所に出た字が、直前の字の処理を途中で打ち切ってしまう。

したがって、**聴覚で警戒すべき向きはfrac課題の2文字版が押さえ、視覚で警戒すべき向きは乙課題が押さえる**という関係になる。両方の課題を両方のモダリティで行って、はじめて双方向の安全が確認できる。

この非対称は、iFontの設計そのものの土台でもある。聴覚と視覚を同じ物差しで結ぶには、向きの違いを吸収した提示を設計しなければならない。2.8節の「前の字が残る条件」は、この非対称から演繹されるものである。

### 3.4 論理の連鎖

```
  乙課題で「200ミリ秒の間隔でも手前の文字の認識は落ちない」ことを示す
      ↓ だから
  孤立して測った曲線を、200ミリ秒の連続提示の場面に持ち込んでよい
      ↓ その曲線が
  frac課題で字ごとに得られる（聴覚68音・視覚78字）
      ↓ 認識率が同じ点どうしを結ぶと
  変換 g ができる（200ミリ秒での対応づけ）
      ↓ gに従って各字の見せ方を設計すると
  音声を聞いている人と字幕を見ている人が、同じ時点に同じだけ分かる
```

この連鎖のどこか1つが欠けると、最後の主張が立たない。133ミリ秒の測定は、この連鎖を将来ほかの速度へ広げられるかを調べる枝にあたる。

## 5. よくある質問

**Q. 乙課題の主判定は200ミリ秒なのに、frac課題の視覚は133ミリ秒でも測るのですか。**
測ります。ただし2つの速度は役割が違います。200ミリ秒は変換gを作るための基準速度で、133ミリ秒は**視覚の曲線が提示速度にどう依存するかを測るための点**です。133ミリ秒でgを作るわけではありません（2.7節、3.1節）。

**Q. 133ミリ秒の測定に、乙課題の保証は要らないのですか。**
測定そのものには要りません。孤立した1文字を測るだけだからです。保証が要るのは、その曲線を133ミリ秒で動く製品に持ち込むときで、それは乙課題の133ミリ秒水準の副次判定が担います。7水準のうちに133ミリ秒が入っているので、追加の測定は要りません。

**Q. 乙課題の133ミリ秒で「干渉あり」と出たら、視覚の133ミリ秒の測定は無駄になりますか。**
なりません。視覚の曲線の速度依存性という知見はそのまま残ります。加えて、使ってよい速度の上限が200ミリ秒と133ミリ秒のあいだにあることが分かります。

**Q. 133ミリ秒でも変換gを作れないのですか。**
作れません。gは聴覚と視覚の曲線を認識率で結ぶものですが、聴覚の曲線は200ミリ秒の1点しかないためです。聴覚の速度を変えるには音源を作り直す必要があり、そうすると音そのものが変わって速度と音響が混ざります（2.2節）。これは本研究の限界として論文にも書きます。

**Q. frac課題に2文字版があるのに、なぜ乙課題が要るのですか。**
測っている影響の向きが違うからです。frac課題は答える文字を系列の最後に置くので、後続による妨害という向きが構造的に測れません（3.2節）。

**Q. 乙課題で2番目まで答えさせるのは、記憶の負荷が高いのではありませんか。**
負荷はたしかにあります。それでも答えてもらうのは、データのためではなく、**後続の文字も同定しなければならないという課題の要求を、運用の場面と同じにするため**です。「1番目だけ答えればよい」とすると後続は無視してよい刺激になり、干渉を小さく見積もる方向——つまり「干渉なし」という結論に有利な方向——にバイアスがかかります。なお1番目を先に答えてもらうので、判定に使う項目の負担は最小になるよう配分してあります（1.6節）。

**Q. どちらを答えるか予告しない方式にすれば、負荷が軽くなるのでは。**
なりません。手がかりを予告しない部分報告法は、符号化の段階で取捨選択できないようにする仕掛けで、負荷を減らすためのものではありません。むしろ**1番目を優先して構えることができなくなる**ため、判定に使う項目の成績を下げる方向に働きます。

**Q. なぜ乙課題を流暢な音声で行わないのですか。**
乙課題は間隔S以外のすべてを固定して、聞き手の側で起きる干渉だけを取り出す設計です。流暢な音声で話す速さを変えると**音そのものが変わる**（母音が崩れ、共調音が深まる）ため、成績が落ちたときに「聞き手の干渉」なのか「音にもともと情報がない」のか区別できません。加えてS＝50〜83ミリ秒は毎秒12〜20モーラに相当し、人間の発話の上限（毎秒8〜10モーラ）を超えます。流暢な音声の居場所は聴覚2文字のfrac課題です。

**Q. なぜfrac課題を「前の字が残る」提示で行わないのですか。**
1文字課題については原理的にできません。frac課題の測定量は「その字をどこまで提示したか」の割合で、隣の字が同じ枠に重なるとこの割合が定義できなくなります。文脈の効果は、対象の字の提示率を定義できたまま前の字の扱いだけを変えられる**2文字課題**で測ります。

**Q. なぜ基準速度が200ミリ秒なのですか。**
外部の基準を持つ点だからです。日本語能力試験のもっとも易しい級の聴解音声とほぼ同じ速さで、競技かるたの読み上げ規則もこの速さです。ただしこの値を前提として固定しているわけではなく、乙課題から「非劣性を保てる最速の速度」を推定して、選択の根拠を実測で置きます（1.7節）。

**Q. 「有意差がなかった」ではだめなのですか。**
だめです。有意差の不在は差の不在の証拠になりません。データが足りないだけでも有意差は出ないので、雑な実験ほど「干渉なし」に見えてしまいます。そこで差が許容できる幅δより小さいことを積極的に検定します（1.4節）。

**Q. 乙課題で「干渉あり」と出たら、実験は失敗ですか。**
失敗ではありません。その場合は**連続提示のもとで測り直す**ことになります。聴覚にはもともと2文字課題があり、視覚も2文字課題を用意してあるので、その枠組みがそのまま使えます。乙課題はどちらの測り方を採るかを決める分岐点であって、どちらに転んでも先へ進めます。

**Q. 「前の字が残る条件」で成績が下がったら失敗ですか。**
失敗ではありません。消えた刺激が後の刺激の知覚を妨げる現象は0.2秒前後で最大になるので、下がる可能性は事前に予測として書いてあります。どちらに転んでも、時間の文脈が視覚でどう働くかについての知見になります。

**Q. かな全体で1本の曲線ではだめですか。**
だめです。字によって難しさがまるで違い、平均を取るとその構造が消えます。字幕の設計で必要なのは「濁点のある字はどれだけ長めに・鮮明に出せばよいか」という字ごとの答えです（2.4節）。

**Q. 水準を足したのに、なぜ試行数まで増やすのですか。**
水準ごとに88観測を確保しないと、字ごとの標準誤差が約5.4ポイントから約7.6ポイントに悪化し、δ＝8ポイントの正当化が崩れるためです（2.9節）。

**Q. 事前登録はしないのですか。**
制度としては行いません。分野に慣行が確立していないためです。代わりに解析計画をデータ収集前に確定し、公開リポジトリのコミットで時点を固定します（4.2節）。

| 提示速度 | 1モーラあたり何ミリ秒で提示するか。iFontの基準は200ミリ秒（毎秒5.0モーラ） |
| frac | 刺激をどこまで提示したかの割合。0％から100％まで21段階。露光時間は frac × 提示速度 |
| 頭打ち | 間隔を十分長くとったときの正答率。その参加者の「急かされていないときの実力」 |
| 非劣性 | 「差がゼロ」ではなく「差が許容できる幅より小さい」ことを積極的に示す枠組み |
| マージン δ | その許容できる幅。データを見る前に決めておく |
| 変換 g | 聴覚の認識率曲線と視覚の認識率曲線を、同じ認識率の点どうしで対応づけたもの。基準速度で定義される |
| 共調音 | 前後の音がたがいの発音に影響しあうこと。前の音の終わりに次の音の準備が現れる |
| 混同行列 | どの字がどの字と取り違えられるかを表にしたもの |
| 統制の問題 | 最後まで提示する、まじめに答えていれば正解できる問題。除外の判定に使う |
| 階層モデル | 全体の傾向と個々の字の個性を同時に推定する枠組み。観測の少ない字を全体の傾向で補える |
