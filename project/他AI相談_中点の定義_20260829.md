# 相談：識別率の「中点」をどう定義すべきか

## 何をしている研究か

音声を途中まで聞かせたときの「どこまで分かるか」の時間変化を測り、
**同じ変化を文字アニメーションで再現する**手法を作っています。

- 音声：かな1文字の音を先頭から t ms で打ち切り、68択のかな表から回答してもらう
- 視覚：かな1文字のアニメーション（薄い→濃い、ぼやけ→鮮明 など）を進み具合 s% で打ち切り、
  同じくかな表から回答してもらう

音声で「20msのとき正答率76%」なら、文字アニメーションでも
「20msのとき正答率76%になる進み具合」を出す。これを全時点でやると、
音声の分かり方を文字で再現したことになります。

## いま決めたいこと

合わせ方の一つとして、**曲線の形まで合わせるのではなく、
「中点に達する時刻」だけを揃える**方式を検討しています。
進み方を歪めないので実装が単純で、較正で測ったとおりの速さで提示できる利点があります。

このとき **「中点」をどう定義するか** が問題になっています。

## 参考にした先行研究（同じ研究室の別論文）

競技かるたの読み上げ音声を比較した研究で、次の定義を使っています。

- 確信度を **0.5（未決心）〜1.0（完全に確信）** の範囲で測る
- 4係数ロジスティック関数を当てはめる：
  μ(x) = L + (U−L) / (1 + exp(−β₁(x − x₀)))、L=0.5, U=1.0
- **x₀ を「聞き分けできるレベル」と定義**（μ(x₀) = 0.75 となる点）
- 「毒性試験における半数致死量（LD50）の考え方を転用したもので、
  未決心状態（0.5）と完全に正解を確信している状態（1.0）の中点である0.75を閾値として用いる」
- β₁ を「傾き」と定義

この定義の良いところは、**下限と上限があらかじめ固定されている**ことです。
0.5と1.0は測り方から決まるので、すべての刺激・すべての読手で同じ基準になり、
比較ができます。

## 今回、そのまま使えない理由

**上限が刺激によって違います。**

音声を最後まで聞かせたときの正答率（8字、各66〜68試行）:

| 字 | 全長での正答率 |
|---|---|
| か | 94.1% |
| あ | 93.9% |
| つ | 84.8% |
| ま | 84.8% |
| ぱ | 63.6% |
| ら | 51.4% |
| し | 42.9% |
| **が** | **2.9%** |

「が」は最後まで聞いても当たりません。**68人中57人が「か」と回答**しています。
合成音声で先頭モーラを切り出した際に濁りの音響的手がかりが失われたためで、
**刺激の不良**です（参加者は「か」だと確信して聞いており、迷っていません）。

したがって「正答率50%」を共通の基準にすると、
**8字中4字（が・し・ら・ぱ）で中点が定義できない**か、ほぼ最終時点になります。

## 検討している案

### 案1：各字の天井の半分
その字が到達した最大の正答率の半分を中点とする。
「あ」なら47%、「が」なら1.5%。**8字すべてで定義できる**が、
**字ごとに基準が変わる**ので、字をまたいだ比較ができない。

### 案2：共通の50%（届かない字は除外）
かるた論文に近い。共通の物差しになるが、**実質4字の実験になる**。

### 案3（いま有力）：50%を基準とし、届かない字はその字の到達点を使う
- 全長で50%を超える字（か・あ・つ・ま・ぱ・ら）→ **正答率50%に達する時刻**
- 届かない字（し 42.9%・が 2.9%）→ **その字が到達した最大値に達する時刻**

## 相談したいこと

1. **案3は統計的・方法論的に妥当か。**
   基準が字によって変わることになるが、「50%か、届かなければ到達点」という
   規則自体は事前に決められるので再現可能です。
   ただし2種類の量を混ぜて比較することになります。

2. **より良い定義はないか。**
   たとえば「下限を当てずっぽう（1/68 = 1.5%）、上限を各字の到達点として、
   その中点」という定義も考えられます（かるた論文の0.5〜1.0を、
   この課題に合わせて 1.5%〜到達点 に読み替える）。
   この場合「が」は 1.5% と 2.9% の中点＝2.2% になり、実質意味を持ちません。

3. **そもそも刺激不良の「が」を含めるべきか。**
   除外すれば問題は小さくなりますが、
   「音声が最後まで識別されない文字では、文字表示も最後まで完成しない」ことを
   再現するのも転写の目的の一つだと考えています。

4. **「傾き」に相当する指標をどう定義すべきか。**
   かるた論文では4PLのβ₁を使っていますが、今回は関数形を仮定しない
   単調回帰で曲線を推定しています（ロジスティックを両側に当てはめると、
   逆変換が一次変換に帰着してしまい、対照条件と区別できなくなるため）。
   単調回帰の曲線から「傾き」に相当する量をどう取り出すべきでしょうか。

## 補足：もう一つの指標も検討中

正答率は「正解か不正解か」しか見ないため、
**「情報が届いていない」と「情報は届いているが答えが1つずれている」を区別できません**。

- 「が」を全長提示：正答率3%だが、**答えは「か」に集中**（68人中57人）
- 何も聞こえない10ms：答えが「つ61・ぷ25・か23…」と**40種類に散る**

そこで応答分布の情報量（相互情報量の字ごとの分け前）も計算しており、
これを目標にすると「が」でも転写が成立します。
**この指標でも同じ「中点」の問題が生じる**ため、
定義は両方に適用できるものが望ましいです。

## データの規模

- 聴覚：90名、8字×7時点＋全長、各時点33〜35試行
- 視覚：325名、8字×4方式×8〜13水準、各セル約122試行
  （紛れ字64字を含めると11,729試行）
