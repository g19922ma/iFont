# Perceptual Score・文字合成・iFont の概念整理（栗原先生相談用）

2026-07-28 丸山（Claude との議論の整理）。ステータス: **提案・未確定**（採否はPI判断）

## 定義

- **Perceptual Score（知覚スコア）**
  文字情報が時間とともに徐々に識別可能になる過程を記述する、モダリティ非依存の中間表現。
  各時点には、その時点までに提示された情報から、**対象**がどの程度識別可能であるべきかが
  記述される（物差しは基準観測者集団の認識率）。
  「対象」は用途により異なる: 競技かるたなら札・歌の候補、1文字実験なら提示されたかな。
  つまりスコアは「文字そのものが分かる」だけでなく、文字情報によって指し示される対象が
  分かっていく過程まで含めて記述する。
  注意: 各文字に独立した識別度を付けるのではない。文字列が時間上に展開されるにつれて、
  届いた情報の累積で対象が絞られていく過程を表す。
- **音声合成**: Perceptual Score を音声として実現する処理。既存のTTS/歌声合成を較正して用いる。
- **文字合成**: Perceptual Score を動的な視覚文字として実現する処理。本研究の新規要素。
  各文字の識別可能性の時間変化と、前後の文字との遷移を制御した動的な視覚信号の生成。
- **iFont**: 文字合成の出力（動的文字）。フォントが文字を字形に写すように、
  知覚スコアを「見え方の時間変化」に写した結果。

対称形: 音声合成:音声 = 文字合成:iFont。
ギャップの言明: スコアを音として実現する手段は既にある（音声合成）が、視覚側には
対応物が存在しなかった。それを作るのが文字合成/iFont である。

## 構図

```
文字列
  → Perceptual Score（対象レベル: 各時点までの累積情報で対象がどこまで識別可能であるべきか）
  →（F=決まり字の組合せ論で、文字レベルの提示要求に翻訳。モダリティ非依存）
  → ┬ 音声合成 → 音声出力       （文字レベルの明瞭度を g の聴覚側で較正して実現）
     └ 文字合成 → iFont（動的文字）（文字レベルの明瞭度を g の視覚側で較正して実現）
```

視聴覚の等価性（「同じ時点に同じだけ分かる」）は、**同一のスコアを共有すること**で保証される。
スコアは対象レベル、合成器は文字レベルで動き、F が両者を橋渡しする。1文字実験は
「対象=かなそのもの（Fが恒等）」の特殊ケースとして同じ定義に収まる。Kikiwake の
f_audio_karuta(t)（実読みでどの時点にどの歌か分かるか）は、実読み音声が実現している
Perceptual Score の実測に相当する。

## 既存部品との対応（全部この枠に収まる）

| 既存部品 | この枠での位置づけ |
|---|---|
| 変換 g | 両合成器の較正表（同じ認識率を実現する明瞭度の対応） |
| frac課題（Stage 2） | 較正表の実測 |
| 乙課題（干渉判定・Stage 1） | 合成器がスコアどおりに実現できているかの検証（干渉=実現の乱れ） |
| 決まり字の組合せ論 F | スコア（対象レベル）と文字レベルの提示要求との橋渡し（モダリティ非依存の既存議論がそのまま正当化） |
| ifont_tool | 文字合成器+音声合成器の実装。内部の設計タイムラインがスコアの暗黙版（明示化候補） |
| 音声品質処方（2026-07-24〜26） | 音声合成器の実装課題 |
| 持続・配置（音は消えるが文字は残せる） | 文字合成器に固有の自由度。中間表現でなく合成器の方針の層 |

## タイトル案（2026-07-28 丸山決定版）

> 文字情報の識別過程を記述する中間表現 Perceptual Score と視聴覚への合成

「iFont：」の接頭辞は外した（iFont は枠組み全体でなく文字合成の出力の名前になったため）。
プロジェクト名としての知名度を優先するなら「iFont：」を頭に残す案・「〜の提案」を付ける案も
あり（比較3案は WORKLOG 2026-07-28 の会話参照）。最終決定はPI。

## 概要の書き直し版（タイトルと同時に確定）

> 競技かるたにおける決まり字の聞き分けのように，音声が部分的に届くにつれて対象の識別が
> 時間とともに進む場面がある．この体験は，聴覚に頼れない人には従来の字幕では等価に得がたい．
> 本研究は，文字情報が時間とともに徐々に識別可能になる過程を記述する，モダリティ非依存の
> 中間表現 Perceptual Score を提案する．スコアの各時点には，その時点までに提示された情報から
> 対象（競技かるたであれば札の候補）がどの程度識別可能であるべきかが記述される．同一のスコアを，
> 音声合成によって音声に，文字合成によって動的な文字表示 iFont に変換することで，視覚と聴覚で
> 「同じ時点に同じだけ分かる」提示が構成できる．スコアの実現は2層に分かれる．どこまで届けば
> 対象が一意に定まるかは，決まり字の組合せというコーパスの性質から決まり，情報が耳から届くか
> 目から届くかによらないため，あらためて設計する必要がない．したがって設計の自由度は，文脈の
> ないかな1文字について，視覚の明瞭度と聴覚の明瞭度とを同一の認識率という物差しの上で文字ごと
> に対応づける変換 g に集約される．g の実測では，認識率を明瞭度に対する心理測定関数として表し，
> 時間ゲート提示によって曲線を直接測る．視覚は0.2秒の提示の中で透明度やぼかしを段階的に解き，
> 聴覚は音の頭から途中までを聞かせて明瞭度を操作する．推定には恒常法と，文字を変量効果に置いた
> 階層ロジスティック回帰を用いる．あわせて，1文字で測った対応を連続提示へ適用してよいかを，
> 直後に次の文字が来ることによる認識の劣化の有無として，事前登録した手続きで判定する．実績の
> ある提示法と数理モデルを基準に据えて新しい提示法を公平に比較し，競技かるたに加えて早押し
> クイズの字幕への一般化を目指す．この枠組みは，同一の Perceptual Score から字幕と音声再生が
> 同期した動画を生成する文字合成器として実装し，コマンドラインツールおよび MCP サーバとして
> 公開した．
