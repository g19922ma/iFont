# 設計案：8字 × 8方式の選別実験（2026-08-26 丸山案）

**状態：検討中。まだ実装していない。**

---

## 1. なぜこの形にするか

較正の解析で、**解析だけでは「どの字にどの方式が合うか」を決められない**ことが分かった。

参加者を入れ替えて400回やり直すと、8字中4字で最良の方式が入れ替わる（し 26%、ぱ 37%、ら 40%、か 42%）。
「一様 vs 空間」の2群にまとめても6字が決まらない。
**順位相関で一度失敗したのと同じ形**なので、解析で決めにいくと再び崩れる。

そこで **「全部作って、実験で落としていく」** に切り替える。

### 落とす理由は2種類（丸山案）

| | 却下の理由 | 測り方 |
|---|---|---|
| ① | **音声と合わない**。その字をその方式で出すと理解度がいきなり上がりすぎる／逆に上がらない | 識別パート |
| ② | **合わせられるが不快**。急に速さが変わる、見ていられない | 快適度パート |

**⚠ 是か非かの線引きは人間が決めることであって、解析で先に決めない。**
較正データから計算できるのは**予測**まで。実際に悪いかどうかは測る。

> このため、**予測で却下されたマスも実験に含める。**
> 除いてしまうと、予測が当たっていたかを永久に確かめられない。

## 2. 何を作るか

### 方式8つ

| | 中身 |
|---|---|
| 単独4 | うすい→濃い ／ 点が増える ／ ぼやけ ／ 端から |
| **組み合わせ4** | 一様 × 空間 の総当たり |

```
  うすい→濃い × ぼやけ
  うすい→濃い × 端から
  点が増える   × ぼやけ
  点が増える   × 端から
```

**組み合わせにする理由**：較正で分かった弱点が互いを埋め合う。

| 方式 | 弱点 | 組むと |
|---|---|---|
| ぼやけ | **床が16.8%**。「まだ誰も分からない」を作れない | 一様と組むと床が下がる |
| うすい→濃い・点が増える | 全変化が **0〜5%** に詰まり、進み具合1%のずれで **27〜38pt** 動く | 空間と組むと広がる |
| 端から | 字の形に強く依存（濁点が右上なので最後に出る） | 一様と組むと依存が薄まる |

**掛け方は「同時」**（同じ進み具合 s で両方を進める）。前後で切り替える案もあるが、
同時の方が素直で、いまのレンダラを2枚重ねるだけで作れる。

### 字は8つ（較正と同じ）

あ・か・が・ぱ・し・つ・ま・ら

## 3. 実験の構成（**2つの集団に分ける**）

**⚠ 同じ人に両方やらせない。** 識別課題を先にやると字を覚えてしまい、
「見やすさ」の評価が「もう知っている字だから見やすい」に化けるため
（もとの実験計画で群Cを独立させたのと同じ理由）。

### パートA：識別（理解度）

| | |
|---|---|
| セル | 8字 × 8方式 × 8水準 = **512** |
| 1人あたり | 8字 × 3点 = **24問**（約6分） |
| 割り当て | 字ごとに方式が1つ当たり、**1人で8方式すべてを1字ずつ**見る |
| 人数 | **320人**（1セル15試行。較正と同じ密度） |

### パートB：快適度

| | |
|---|---|
| マス | 8字 × 8方式 = **64** |
| 1人あたり | 8マス（1本20秒で約3分） |
| 人数 | **120人**（1マス15人） |

**群Cの実装（1字／5字横並び／5字入れ替え）を流用する。**
ただし字ごとに聞く形に変えるので、提示のしかたは1字に絞るか、
5字の並びを字ごとに作り直すかを決める必要がある。

### 費用の目安

較正の実績（250人が1分以内・約1万円）から、**合計440人で約1.8万円**。

## 5. 較正データから計算できる「予測」（実験前に固定する）

実験を回す前にこの予測を凍結し、**当たったかどうかを後で照合する。**

### 予測1：識別の立ち上がりがフレーム間隔より速い字は転写できない

実測（生データ・当てはめではない）：

```
  あ  10ms →  0.0% ／ 20ms → 75.8%    10ms で 76pt 上がる
  ま  35ms →  3.0% ／ 50ms → 73.5%    15ms で 71pt 上がる
  か  10ms → 12.1% ／ 85ms → 97.1%    75ms かけて上がる
```

参加者の画面は**中央値 58Hz（1コマ 17.2ms）、実測は 4〜198Hz とばらばら**。

> **あ と ま は、1コマの間に理解度が 70〜91pt 飛ぶ。**
> **か だけが 4〜5コマに分けて描ける。**

**予測**：あ・ま はどの方式でも「音声と合わない」で却下される。か は通る。

### 予測2：誤差への強さは方式で25倍違う

進み具合が1%ずれたときの正答率のずれ（参加者ブートストラップ300回）：

| 方式 | 点推定 | 95%区間 |
|---|---|---|
| ぼやけ | **1.4pt** | [1.2, 2.3] |
| 点が増える | 16.6pt | [12.4, 21.4] |
| 端から | 32.9pt | [10.3, 203.4] |
| うすい→濃い | 34.4pt | [20.8, 61.7] |

**予測**：低fpsの端末では、うすい→濃い・点が増える の成績が落ちる。
ぼやけは落ちない。**組み合わせ方式は中間になる。**
（`refresh_hz` を記録しているので後から層別できる。）

### 予測3：濁点は空間的な方式で不利

較正の実測（交互作用の検定1本、p=0.0055）：

| 方式 | 濁点による低下 | 中点の伸び |
|---|---|---|
| うすい→濃い | +9.5pt | 1.13倍 |
| 点が増える | +13.4pt | 1.25倍 |
| ぼやけ | +15.3pt | 1.19倍 |
| 端から | +15.8pt | **1.82倍** |

**予測**：が・ぱ は 端から を含む方式で不利。組み合わせると和らぐ。

| | 作業 | 重さ |
|---|---|---|
| 1 | **組み合わせレンダラ4つ** | 軽い（既存を2枚重ねる） |
