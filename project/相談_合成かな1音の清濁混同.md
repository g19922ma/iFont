# 相談：合成した日本語かな1音の「ぱ行」が濁音に聞こえる問題

（他のAI・専門家への相談用。この文書だけで前提が分かるように書いてある。2026-08-18）

## 私たちが何をしているか

日本語のかな1文字（1モーラ）が「音声でどれだけ聞き取れるか」「文字表示でどれだけ見分けられるか」を
測る心理実験を準備している。音声刺激は次の手順で作った68音（を・ぢ・づ・ゔは同音のため除外）：

1. 音声合成ソフト VOICEVOX（話者：東北きりたん）で、かな1文字だけを単独発話として合成
2. 音の高さを B3（246.94 Hz）に平坦化（抑揚をなくし、文字間の条件を揃えるため）
3. 1モーラの長さを 0.2 秒ちょうどに整形
4. 音量を68音の間で揃える（有音部の実効音量を中央値基準で正規化）
5. mp3化し、Web実験ページで頭から一部だけ再生して打ち切る（どの時点で聞き分けられるかを測る）

## いま起きている問題

人間（共同研究者）が全音を試聴したところ、**「ぽ」などのぱ行（p音）が、濁点つき（ぼ などの b音）に
聞こえる**という報告があった。また全体に単独1音・平坦音程・0.2秒固定という加工のため、
自然な発話よりロボット的に聞こえる（これは許容範囲としている）。
問題にしたいのは「不自然」ではなく「**別の音に聞こえる**」水準の混同である。

## これまでに打った対策（それでも残っている）

- 背景知識：無声破裂音（ぱ行・た行・か行）と有声破裂音（ば行・だ行・が行）を分ける主な手がかりは
  VOT（voice onset time：破裂から声帯振動が始まるまでの時間。自然な日本語で25〜45ミリ秒）と
  破裂の強さ。VOTが短い・破裂が弱いと有声側（濁音）に聞こえる。
- 対策1（自動修正）：合成後の音を測り、VOTが不足する音は子音を伸ばす倍率を段階的に上げて
  再合成する仕組みを導入済み（それ以前は「ぴ→い」「ぷ→ぐ」「ぽ→ご」の誤聴報告があった）。
- 対策2（1字ずつの処方）：ぱ行は字ごとに個別の合成パラメータを指定。
- 対策3（文脈切り出し）：最重症の「ぽ」は単独合成を諦め、「オッポ」という語を合成して
  その中の「ポ」を切り出して使っている。
- それでもなお、試聴で「ぽ」に濁りを感じるという今回の報告に至った。

## 疑っている要因（仮説）

1. 低い音程（B3=247Hz）への平坦化で、破裂音の高域成分が相対的に弱くなっている
2. 音量正規化が母音を持ち上げ、破裂（バースト）との強度比が崩れている
3. mp3圧縮が破裂の鋭い立ち上がりをなまらせている
4. 再生環境（PCやスマートフォンのスピーカー）が高域を落とし、破裂がさらに弱く届く
5. 単独1音のため、聞き手が話速や文脈から有声・無声の境界を較正できない
   （文脈があれば正しく聞こえる音が、単独では曖昧になる）

## 質問したいこと

1. 上の仮説のうち、どれが効いていそうか。切り分けるにはどんな音響測定・実験をすればよいか
   （例：バーストの強度スペクトル、VOT実測、mp3前後の比較、など具体的な手順がほしい）。
2. 単独の短いかな1音で無声破裂音を「無声らしく」聞かせるための、音響加工の定石はあるか
   （バースト増強、気息成分の付加、VOT延長の限界、など）。
3. 心理物理実験の設計として、こういう「素材の時点で混同されやすい音」はどう扱うのが標準か。
   選択肢として考えているのは：
   a. 混同も測定対象として受け入れる（68択の課題なので混同行列ごと測れる）。ただし
      「全部聞かせても当てられない音」が注意チェック問題（全長提示で正答して当然の問題）に
      出ると誠実な参加者が失点するので、チェック問題からは除外する
   b. さらに音響処方を重ねて直してから実験する
   どちらが良いか、他の観点はあるか。
4. 参考になる文献・先行研究（合成音声の単独モーラ知覚、VOTと話速、清濁の知覚境界）があれば。
