# 相談：視覚の識別率を「絵 × 表示時間」の式にできたかもしれない（2026-08-27）

**前提知識ゼロで読める形にしてある。数値はすべて実測。**
研究全体の背景は `project/他AI相談_実験計画_20260826b.md` にあるが、この文書だけで議論できる。

---

## 1. 何を測っていたか（30秒で）

ひらがな1字が**だんだん現れるアニメーション**を途中で止め、何の字か当てさせる実験
（クラウドソーシング・163人・9,957試行・72択強制選択、当てずっぽう率 γ=1/72≒1.4%）。

方式は4つ：うすい→濃い（fade）／点が増える（reveal）／ぼやけ→はっきり（blur）／端から現れる（wipe）。

もともとの目的は「進み具合 s → 正答率」の曲線 V(s) を測ること。
そこに**速さ2水準（基準300ms/500ms）**を仕込んであった。

## 2. 偶然できていた「同じ絵・違う時間」の比較

速さを変えると、**止めたときの絵（進み具合）は同一のまま、字が画面に映っていた時間だけが変わる**
ことが分かった（終点は必ず指定どおりの進み具合で描画される。実測で9,490件が名目値と完全一致）。

これで「**同じ絵を、短く見せた場合と長く見せた場合**」の比較が **19ペア**できた。

### 時間の定義（重要）

1トライアルはこう進む：

```
  0ms      17ms           50ms
  ├─空白────┼──字が見える───┼─白紙─→ 回答（かな表から選ぶ）
```

- **T ＝ 字が画面に映り始めてから白紙になるまでの時間**（式で使うのはこれ）
- 終点の絵の保持は**全条件で33ms（2コマ）に固定**。速さを変えても変わらない
- したがって T の差は「**途中の絵も含めて、字の何らかの姿が見えていた時間**」の差

⚠ 緩さが1つ：薄い水準では途中の絵≒終点の絵なので「同じ絵の表示時間」とみなせるが、
ぼやけの高い水準では T の大半が「もっとぼやけた途中の絵」の時間である。
式はそれを区別せず T として数えている。

## 3. まず観察された事実

19ペアを「短い方の正答率」で層別すると：

| 層 | ペア数 | 時間を1.2〜1.6倍にしたときの正答率の差（平均） |
|---|---|---|
| 天井ぎわ（80%超） | 9 | **+0.0pt**（SD 2.7） |
| **中間（20〜80%）** | 7 | **+4.8pt**（SD 8.3） |
| 床ぎわ（20%未満） | 3 | **−0.2pt**（SD 1.6） |

**天井と床ではまったく動かない。動くとすれば中間だけ。**
（著者の直感「最大限見えるようになったら変わらない」がデータと整合した。）

## 4. 式

**飽和指数モデル**を当てはめた：

```
    p(絵, T) = γ + (λ(絵) − γ) · (1 − e^(−T/τ))

      γ     = 1/72（固定）
      λ(絵) = その絵から最大限読み取れる割合（セルごとに最尤推定）
      τ     = 読み取りの時定数（全セル共通で1つ）
```

### 当てはめの結果

- τ を 10〜1000ms でグリッドサーチ（各 τ で λ はセルごとに最尤）
- **最良 τ ≒ 20ms**（対数尤度のピークは 15〜20ms。25ms から悪化、40ms 以降は急落）
- **19セル中18セルで、予測と実測が誤差2SE以内で一致**

例（予測/実測、%）：

```
  ぼやけ 56%    短 62/62   長 62/62
  ぼやけ 84%    短 95/96   長 95/95
  端から 25%    短 30/30   長 30/30
  うすい 3.5%   短 80/84   長 90/90
```

### 解釈

> **字の姿が約20ms（3τ≒60msでほぼ完全に）画面にあれば、
> その絵から読み取れるものは読み取り終わる。以後は時間を足しても変わらない。**

- 天井・床で時間が効かないのは式から自動的に出る（λ−γ が小さく動く余地がない）
- 較正・検証の提示時間は最短33ms ＝ 1.65τ なので、**「V は s だけの関数」という
  転写手法の前提は、1−e^(−1.65) ≒ 81% まで飽和した領域で成り立っている**
  （50msなら92%、66msなら96%飽和）

## 5. 式で説明できない1点

**「点が増える」4% だけが外れる：**

```
  実測    33ms → 69.7%（201試行）    50ms → 90.4%（104試行）
  式の限界 λ=100% に置いても、50ms で 83.2% が上限
  差      7.2pt ＝ 実測の標準誤差（±2.9pt）の 2.5倍
```

λ≤1 の制約下では、**どんな τ を選んでもこの上がり方は再現できない**
（33msで70%も読めているなら上限に近いはずで、+17msで90%には届かない）。

この点は独立に確認済み：
- 参加者を入れ替えるブートストラップで +20.7pt [+10.3, +30.6]、p=0.0005
- 字を入れ替えても +20.7pt [+10.2, +31.8]（特定の字に依存しない）
- 19比較のHolm補正を通過
- 2群に偏りなし（他セルでの正答率 49.7% vs 48.5%、端末構成も同等）
- 終点の絵は完全に同一

## 6. 聞きたいこと

1. **この式とτ≒20msという値は、視覚心理の既存知見と整合するか。**
   単純図形の識別で時定数20ms前後という報告はあるか。逆にτがもっと長い
   （100ms超）という文脈があれば、この当てはめのどこかがおかしいことになる。

2. **「点が増える 4%」の逸脱に説明はつくか。**
   点描（ランダムドット）だけが飽和指数から外れる機序の候補はあるか。
   例：ドットの時間的な蓄積（確率的サンプリング）、マスキング、
   途中の絵（3.33%の点）が独立な手がかりを足す、など。
   それとも 32回比較して1回の偶然（多重性は Holm で処理済みだが）と見るべきか。

3. **論文（WISS 2026、6ページ、締切8/31）にこの式を載せるべきか。**
   載せるなら「手法の前提を守る材料」（4節の解釈）としてか、
   「探索的な副産物」としてか。post-hoc の層別と当てはめであることは明示する前提。

4. **T の定義の緩さ（途中の絵を含む）は致命的か。**
   「終点の保持は全条件33msで固定、変わったのは接近過程の長さ」という事実を
   どう表現に反映すべきか。
