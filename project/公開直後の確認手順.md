# 公開直後に確認すること（較正フェーズ）

**2026-08-25 作成。掲載が始まってから最初の数人が来た時点で、1回だけ通して読む。**

較正フェーズは審査が通って「掲載準備中」になっている。**掲載が始まると中止も編集も
できない**ので、ここで見つけられるのは「止めるか、走らせながら手当てするか」の判断材料だけである。

---

## 使う道具

```bash
python3 experiment/tools/watch_transfer.py
```

**前回見た時刻を控えているので、繰り返し実行しても増えたぶんだけを読む**（Firestore の
読み取り回数を抑えるため）。最初から見直したいときは `--since 20:00` や `--reset`。

---

## 1. いちばん大事：本物の参加者が「本番扱い」で記録されているか

```
  時刻     参加者ID        コード      集団      扱い        問    正答
  19:30  m4k7pq       ABC123   aprime  本番        70    38
```

**確かめるのは2つだけ。**

| 見るところ | 正しい状態 |
|---|---|
| 参加者ID | **配布した6文字の英数字**（`m4k7pq` のような形） |
| 扱い | **本番** |

⚠ **参加者IDが `anon-` で始まっていたら、URL から `wid` が落ちている。**
その場合は全員が試し打ち扱いになり、**集めたデータが分析の既定から丸ごと外れる。**
道具が自動で警告を出すので見落とさない。

⚠ **配布リストにあるのに「テスト」と出ていたら、設定と設問ファイルが食い違っている。**
`experiment/tools/write_distributed_ids.py` を走らせ直す。

## 2. 送信の取りこぼし

完走レコードに `send_failures` が入っている。**0 に近いか**を見る。

2026-08-25 に、栗原先生が電車内で通された回で **70問のうち60問ぶんが届かなかった**。
いまは送れなかった記録を貯めて送り直すようにしてあるが、**効いているかは実データでしか
分からない。** 何人か完走したところで確かめること。

---

## 3. 水準が床と天井を取れているか

較正フェーズは**募集を止めずに走らせつつ、届いた順に見る**（→ `掲載文.md` 1.2）。
最初の数十件が届いたら、次を確認する。

- 打ち切りなしの問題（確認問題A・全部聞かせる／全部見せる）の**正答率が十分高いか**
- 字ごとの曲線が、いちばん薄い時点で**正答率が十分低く**（床）、全長で**十分高い**か（天井）
- 方式ごとに曲線が描けているか

⚠ **2026-08-25 に「ぼやけ」の水準を置き直した**（42%まで 0/20 で床に潰れていたため）。
新しい配置（26, 38, 48, 56, 64, 72, 84, 100）で床と天井が取れているかを、
**まず確かめるべきはここ**である。

⚠ **掲載後は水準を変えられない。** おかしくても走らせ切るしかない。
そのときは「この方式は曲線が描けなかった」と論文に書くことになる。

## 4. 所要時間

掲載の目安時間は **10分**。実測は視覚 339秒（約5.7分）・聴覚 237秒（約4.0分）だが、
**答える速さの個人差が大きい**（同じ70問で237秒と410秒）。

完走レコードの `duration_s` を見て、**目安を大きく超える人が多くないか**を確かめる。
超えているようなら、次の掲載（検証フェーズ・群C）で目安時間を上げる。

## 5. 承認の作業

| 判断 | 条件 |
|---|---|
| 承認 | 提出された完了コードが、**完走レコード**（`transfer_wellbeing` の `record_kind = "session"`）にある |
| 承認（データは分析から外す） | 完走はしたが、確認問題を落としているなど回答の質が低い |
| 非承認 | 完了コードが記録に無い／他の人のコードと重複している |

**「データを分析から外す」ことと「報酬を払わない」ことは別**にする。最後までやってくれた人には払う。

⚠ **審査の方が開かれた5件が名簿に入っている**（2026-08-25。回答は0問）。
その設問を受け取った参加者は「続き」として同じ割付番号に入るので、**割付に穴は空かない**。
回どうしは**完了コード**（1回ごとに新しく作られる）で分けられる。

## 6. 分析するとき

```bash
python3 experiment/tools/analyze_transfer.py \
    --in dump.json \
    --only-ids "project/設問データ_一部だけ見えた文字・聞こえた音を当てる問題_0825_v2.tsv"
```

`--only-ids` を付けると**配布した253個のIDの行だけ**が残り、研究者・指導教員の試し打ちは
自動的に外れる。**本番の参加者が1行も残らないときは警告が出る**（`wid` が渡っていない恐れ）。
